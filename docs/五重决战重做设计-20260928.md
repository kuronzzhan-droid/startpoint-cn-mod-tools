## 0. 结论先行

1. 【事实】两轮总血量相同（多人约 3000 亿），但**第 0 轮是 BothBoss 本地副本轮**：队友只同步扣血，眩晕槽、试炼计数、对 boss 的减益、Fever 都只算自己。第 1 轮才是真协力，全部三人共享。难度倒挂是结构性的。
2. 【事实】场景二地形（克隆自官方地狱沙漠）上下两层各有 4 个 Fever 攻击累积道具（+25%/个，上限 +500%），第 1 轮 Fever 同步、两波间不清空 ⇒ 下半场滚雪球的主因。
3. 【事实】跨轮只保留技能槽比例、瞬发累计加成、触发计数；增益、固有状态层数、Fever、连击都清零。反暖机有官方模板：强制驱散（含不可驱散/固有层）、技能槽清零、禁益场、强制结束 Fever。
4. 【事实】两轮共用一个时钟：总时限 = 第 0 轮隐藏关的 c111（现 18 分钟），第 1 轮的 c111 不加时。
5. 【事实】随机选图补丁 V7 已在本机 APK；多人每局结算后服务端解散房间 ⇒ 下一局新房号 = 新种子；单人按时间播种。把所有路由行改成「人人命中」的平凡条件，三人候选池相同 ⇒ **每局随机抽一套阵容且全房一致，不需要新 APK**。
6. 【事实】图集预算：每个阶段（一个隐藏关的全部波次）加载的不同 boss 贴图并集 ≤5.5 Mpx 为通过，≤6.0 为警告（需蒙特卡洛），>6.0 拒绝。现网 22 关里 14 关超标（11 关带始龙之眼 4.46 Mpx）。
7. 【事实】外溢：嫉妒试炼 ×3 改在官方共用 routine 上，已影响官方 1033001–04；zone 里直接用了 3 个官方代号（管理者/嫉妒/画龙）。场景一地形缺 FUNNEL_SPAWN6/8，管理者的召唤物静默不出。
8. 【事实】结算：LevelNext 前被隔离的成员、房主中途放弃后的队友，结算回 400（白打 + 弹回登录）。灰服跑的就是我方这套五重 HTTP。

## 1. 新结构

| | 第 0 轮「试炼回廊」（R0） | 第 1 轮「深界王座」（R1） |
|---|---|---|
| 性质 | 本地副本：各打各的，只同步扣血 | 真协力：全部共享 |
| 出场 | 3 只顺序出场（c22=1） | 第一波 2 只同屏（c22=0）+ 第二波「王」1 只（可带 1 个随从） |
| 机制尺度 | **按一个人能完成配**：眩晕槽、试炼次数按单人 | **按三人配**：眩晕槽、试炼按三人合计，王带血量保底（Withstand）阶段 |

| 反暖机 | 无 | 进场清算：强制驱散全部增益（含固有层）+ 技能槽清零 + 短时禁益；之后周期强制驱散、boss 自叠攻加速 |

## 2. 随机性三层

1. **阵容抽签（每局）**：R0 变体 × R1 变体全组合写进 `both_boss_map`，每行平凡条件（Attack≥0）⇒ 三人候选池相同，V7 按房号种子抽一行，全房一致；结算解散房间 ⇒ 下一局重抽。单人按时间种子。
2. **词缀抽签（随阵容）**：每个变体自带一套词缀包，不同变体词缀不同 ⇒ 组合随机。
3. **战斗内随机（第三批）**：王的克隆 routine 放「事件抽签」state（多目标 next_state 均匀抽，官方 7 个 routine 先例，全房一致），抽签点放在首次眩晕/血量阈值之后（避开「同房开局同签」）。DSL `ConditionalsProbability` 对敌方**禁用**（三端各抽各的）。

## 3. 词缀库（第一批）

敌方（quest c74–c83 五槽 + boss 自强化）：
