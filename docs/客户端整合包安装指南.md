# 客户端整合包安装指南

> **重要说明：本仓库不再分发任何客户端整合包或 APK。**
> 如需使用自备原版客户端制作补丁并连接本地自建服务端，请阅读新手入门教程 **[`docs/tutorial/03-安装客户端并连接.md`](tutorial/03-安装客户端并连接.md)**（客户端补丁能力档案说明另见 [`docs/guide/客户端补丁与APK.md`](guide/客户端补丁与APK.md)）。
> 本文仅作为历史五合一客户端补丁组成说明留档备查，原有 Release 下载链接均已移除。

> ⚠️ **风险与免责**：客户端补丁仅限个人在**本机 / 局域网自建服环境**下学习研究交流，一切风险自负。请勿用于商业用途，请支持正版。仅支持 Android。

> **历史版本记录（v2.0，2026-07-19）**：五合一补丁，支持三位自制角色。
> 更早的 v1.0 仅有深渊门控、不支持新角色（不同签名包升级须先卸载旧版再重装，存档可在服务端按 `device_id` 重绑）。

## 这是什么

一个打过**五合一补丁**的世界弹射 CN 客户端方案，配合对应分支的 `startpoint-cn` 服务端（增量链尾 `1.4.107`）运行：

| 补丁 | 作用 |
|---|---|
| ① 免登录 + ② 服务器重定向 | 跳过官方停服登录校验，直连目标服务端 |
| ③ 深渊装备战斗门控 | 15 把深渊武器/能力魂（`8000101`–`8000115`）只在 Rush `700099` / 挑战 `2001` / 练习 `1`–`97` 生效，其余关卡与官方一致（fail-closed 白名单） |
| ④ 赛瑞斯双形态 P-code | 特殊演出预载/双形态动画/湿润雷伤终乘/退场充能——缺它领了赛瑞斯放特殊演出必崩 |
| ⑤ 逐角色像素占屏（render-scale） | 自制角色原生大像素与官方角色等大显示 |

**配套服务端内容**（数据在服务端侧，客户端仅提供对应渲染与门控能力）：

- 「深渊连战」roguelike（Rush 700099，每轮不同 boss）+ 15 把深渊武器 + 代币兑换商店
- 三位自制角色（服务端邮件发放）：**苍海龙王·赛瑞斯**（129999，水，双形态龙王）/ **夏日女神·史黛拉**（139999，光，能力攻击辅助）/ **白狼骑士·杰拉德**（149999，光，月耀一闪）

## ‼️ 自建服请自行打补丁指向本机服务端

客户端的 ② 号补丁会把服务端地址写进 SWF 配置。**自建本地服务端时**，请直接按照 [`docs/tutorial/02-部署服务端.md`](tutorial/02-部署服务端.md) 与 [`docs/tutorial/03-安装客户端并连接.md`](tutorial/03-安装客户端并连接.md)，在自备原版客户端上填入你自己的 `<电脑局域网IP>:8001` 并签名安装。

## 安装与换包注意事项

1. 准备按自身服务端地址打包并签名的客户端 APK（本仓库不提供 APK 下载，制作步骤见 [`docs/tutorial/03-安装客户端并连接.md`](tutorial/03-安装客户端并连接.md)）。
2. **先卸载**设备上已有的《世界弹射物语》（签名与官方或其他版本不同时无法覆盖安装；卸载会清除本地设备身份，重装登录会创建新号，老存档可在服务端按 `device_id` 重绑）。
3. 安装后启动游戏，客户端会自动从你连接的服务端拉取增量更新（更新过程中请勿强行结束进程）。
