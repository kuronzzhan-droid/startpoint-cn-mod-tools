## 这是什么

一个打好**五合一补丁**的世界弹射 CN 客户端，配合服务端 [startpoint-cn](https://github.com/kuronzzhan-droid/startpoint-cn)（`release/modes-20260714` 分支，增量链尾 1.4.107）游玩：

| 补丁 | 作用 |
|---|---|
| ① 免登录 + ② 服务器重定向 | 直连它指向的那个私服 |
| ③ 深渊装备战斗门控 | 15 把深渊武器/能力魂（`8000101`–`8000115`）只在 Rush `700099` / 挑战 `2001` / 练习 `1`–`97` 生效，其余关卡与官方一致（fail-closed 白名单） |
| ④ 赛瑞斯双形态 P-code | 特殊演出预载/双形态动画/湿润雷伤终乘/退场充能——缺它领了赛瑞斯放特殊演出必崩 |
| ⑤ 逐角色像素占屏（render-scale） | 自制角色原生大像素与官方角色等大显示 |

**能玩到的内容**（全在服务端，客户端只是配套）：

- 「深渊连战」roguelike（Rush 700099，每轮不同 boss）+ 15 把深渊武器 + 代币兑换商店
- 三位自制角色（服主邮件发放）：**苍海龙王·赛瑞斯**（129999，水，双形态龙王）/ **夏日女神·史黛拉**（139999，光，能力攻击辅助）/ **白狼骑士·杰拉德**（149999，光，月耀一闪）

## ‼️ 必须配合它指向的那个私服

本包硬编码指向服主自己的服务器。连官服无效；**想自建服的人不要用本包**，照服务端仓库的
[部署攻略](https://github.com/kuronzzhan-droid/startpoint-cn/blob/release/modes-20260714/docs/%E9%83%A8%E7%BD%B2%E6%94%BB%E7%95%A5.md)
重打指向你自己服务器的客户端。

## 安装步骤

1. 下载 [`WorldFlipper-abyss-v2.apk`](https://github.com/kuronzzhan-droid/startpoint-cn-mod-tools/releases/tag/v2.0-threechar)。
2. **先卸载**手机上已有的世界弹射（本包签名与官方/v1.0/其他版本都不同，无法覆盖安装；卸载会抹掉本地身份 → 开新号，找服主按 `device_id` 重绑老存档）。
3. 安装 → 启动后自动从私服拉增量更新到 1.4.107（更新中别强杀进程）。
4. 邮箱领取三位角色（服主发放）。
