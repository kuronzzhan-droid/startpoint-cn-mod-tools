# 模式工坊（D1）

BOSS 工坊提供「五重决战 · 结构」和「深渊连战」。五重详情也有结构入口。
使用当前编辑台的 ManifestView；草稿在 `work/studio-drafts/modes/five/` 和
`work/studio-drafts/modes/rogue/`，交付在 `work/studio-deliveries/modes/`。
不会调用旧发布器、一键重开 CLI、存档库、设备或服务端换期接口。

## 五重结构

读取 `five_boss_v2_spec.json`，展示 rounds、bosses、affix_params、variants、budget。
数值和词缀列表可编辑；素材来源、输出路径、身份不在此页编辑范围。未知语义保留原键名。
保存重新执行与 load_spec 共用的解码器、原构建器 DSL 构造检查、引用和预算检查，
展示草稿相对仓库 spec 的差异。只写独立草稿，不修改仓库 spec。

结构构建通过 Live 注入当前视图，包括 HP 曲线和贴图尺寸。保留当前美术，不重新制作
旧美术，也不执行旧构建器的嫉妒还原。CLI 参数及写入/发布入口保持原边界；
仓库默认规格现已回写链尾调整，因此使用默认 spec 的旧 CLI **产物内容会变化**，详见下文。

用**未修改的仓库 spec**重建一份对照，逐键及逐资源与链尾比较。AMF 资源比较解码后的
语义，避免单纯压缩差异误报。任何差异均显示警告并禁用生成，防止旧规格覆盖后续
驱散、血量、状态或其他修复。编辑草稿不能豁免此门禁；须先在独立维护流程里核对并
回写规格。预算通过仅是静态检查，不代表运行时贴图装箱或多人房实测通过。

审计也覆盖默认未启用、链尾已存在的词缀 DSL。草稿新增触及的现有文件或表键若无仓库
基准可比较，仍阻断生成。贴图依次读取 common、medium、android；输入摘要包含命中前
所有缺失的根，后续出现高优先级资源也会使草稿过期。旧单根摘要草稿须重新预览保存。

### 默认规格更新与旧 CLI 差异

规格对齐到本次只读解码的 1.4.351：副本体力 c69=18、Boss HP c99=0.04375；
其余 HP 槽保留 40/6。五类首领攻击分母由 `bosses.*.attack_divisor` 明确配置。
R0 狂暴仅作用自身，R0/R1 不再附加旧耐性，周期沉默不再强制施加；王的封印及驱散
间隔为 1000 帧。R0 非首位首领只挂狂暴；每波首位使用 entrance，其他首领使用 entrance_self。
`entrance` 定义弱体抗性、五层独立防御及玩家攻击/防御减益；实际第二层为 0.4048。
两条入场程序也由规格编译并接受漂移审计，不能从链尾原样复制来绕过规格维护。
`tier_actions` 保留两类首领 100 档 c149 的预载程序引用。地形移除 FUNNEL_SPAWN7，
重建召唤锚时从保留对象的最大 ID 之后分配，避免把即将删除的锚计入 ID 起点。

默认五重 CLI 因此会生成上述新数据和两条 v3 入场 DSL；不会自动应用到 store 或服务器。
新增参数缺省仍保留旧 DSL 函数行为，旧自定义 spec 不会自动获得入口和数值调整；
地形对象 ID 分配修复适用于所有使用 object_overrides 的规格。
深渊 CLI 的选池、数值、发布和写入分支未变，本次重命名修复只作用于编辑台候选适配层。

## 深渊连战

读取当前视图活动 700099、当前轮数、每层场地、属性、效果及内容指纹。
排行榜运行期号不属于客户端视图，因此明确显示未读取；不会用本地旧记录假装当前期号。

输入 uint32 种子或随机种子，沿用 rogue_build 的选池、数值、领域、布局计划和规则，
保留当前轮数；默认参数与原脚本一致。构建和锻造产物在内存收集，不触发写入或发布分支。
每次调用有独立模块缓存，所有战斗数据读取绑定同一视图，不修改进程全局 store 配置。
保存记录实际读取成员的摘要及候选输出摘要；生成重新编译，输入或产物变化则要求重新预览保存。
相同种子还依赖相同视图、构建规则和布局/历史输入，不能跨不同基线宣称产物相同。

旧 CLI 会删除上一塔的克隆。编辑台交付对新克隆图分配内容摘要后缀，重写对应 CSV 引用，
合并回当前链尾并保留旧键；未修改的共享表顶层块保留原字节。新克隆不混入旧克隆等级或状态。
重命名后再次运行 rogue_validate 引用门禁，交付仍运行完整 key-diff，绝不放宽删除检查。
仅重命名本轮重建的克隆，原有特殊首领和旧命名空间保留；CSV 单元格内列表按完整代号改写。
大蛇父级 c24 的八个头部必须有 general_boss 可用等级与 boss_level 记录。
所有嵌套层级的克隆键碰撞均拒绝；合并后无语义变化的共享表不打进交付。
刷新页面可恢复经过版本、输入摘要和链尾新鲜度核验的草稿预览；生成时仍重新编译并核对输出摘要。
静态门禁、预算警告、APK 资源假设和运行时检查分别记录，未实测项目保持“待验证”。
本页仅重抽战斗内容，保留当前活动元数据、奖励和无尽修正曲线；楼层身份变化会拒绝。

结果列出清进度、结算换期及重启的手工步骤和命令占位符。这些命令不会被编辑台执行。
不要用旧 reroll --apply 来补做手工步骤，它会再次重抽并发布。

## 交付与接口

模式交付复用现有的编译后交付管线：ZIP、check、客户端兼容、APK 内置键、key-diff、
只读预演，以及现有受机器配置约束的应用/撤销接口。新增入口不扩大应用权限。
只有来源版本等于当前已核验 manifest 链尾才可生成；非当前视图、历史视图、清单读取错误
或额外 ZIP 超出链尾均阻断。构建成功、预演成功和设备实测是分别报告的状态。

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| GET | `/api/modes/five`、`/api/modes/rogue` | 当前内容、草稿、五重漂移检查 |
| POST | `/api/modes/<mode>/preview` | `{ "payload": <完整spec或{"seed":123}> }`，不落盘 |
| POST | `/api/modes/<mode>/save` | 同上加 `revision`，重新校验并保存；修订冲突拒绝 |
| POST | `/api/modes/drafts/<mode>/build` | 现有生成请求及后台任务协议 |
| GET | `/api/modes/deliveries` | 可用 `cid=five` 或 `cid=rogue` 筛选 |
| GET/POST | `/api/modes/deliveries/...` | 复用现有详情、文件、预演、应用、撤销及导出路由 |

所有 POST 仍经过 Host、Origin、JSON 类型和会话 token 守卫。预览不预留资源、不写草稿。
`ok` 表示构建校验是否完成；`canGenerate` 还受规格漂移和链尾新鲜度限制，必须分别显示。
