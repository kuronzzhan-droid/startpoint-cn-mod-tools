# 2D 序列帧只读预览

`wf_preview_2d.py` 是独立于服务端、CDN、store 和 `wf_gui.py` 的本地只读预览器。它只读取命令行显式指定的目录，不读取 `profiles.json`，也没有保存、发布或修改源文件的接口。

## 支持的输入

### 普通 PNG 连续帧

目录内直接放置 PNG，例如：

```text
preview/
  idle_0001.png
  idle_0002.png
  attack_0001.png
```

文件名末尾的十进制数字是帧号，前缀是序列名。没有数字后缀的 PNG 会归入 `default` 序列。

### WF 像素动画

可以传角色包根目录，工具会进入其 `pixelart/` 子目录；也可以直接传 `pixelart/`：

```text
character-package/
  pixelart/
    sprite_sheet.png
    sprite_sheet.atlas.amf3.deflate
    pixelart.frame.amf3.deflate
    pixelart.timeline.amf3.deflate
```

元数据也可使用同名 `.json` 文件。`--variant special` 可选择 `special_sprite_sheet.png` 与 `special.*` 元数据；`auto` 在同时存在两组时优先常规组。

### 封印角色工作区

可直接传入 `wf-release-v1 adopt-character` 生成的 workspace 根或其中的 `package/`。预览器只从
`manifest.json` 的 `roots.common[].logical_path` 查找唯一的角色 `pixelart` 根，不递归猜测同名目录：

```powershell
python -X utf8 wf_preview_2d.py D:\isolated\rolf-character-workspace --open
python -X utf8 wf_preview_2d.py D:\isolated\rolf-character-workspace\package --describe
```

国服资源把 PNG signature 存为 `89 70 6e 67 ...`；预览响应仅在内存中恢复标准 PNG signature，
不会改写包内文件。罗尔夫实际封印包可识别常规像素动画的 9 个序列、428 个 timeline 帧。
`--variant special` 可切换技能/特殊像素组。

## 启动

```powershell
python -X utf8 wf_preview_2d.py D:\path\to\preview --open
python -X utf8 wf_preview_2d.py D:\path\to\character-package --variant normal --port 8766
python -X utf8 wf_preview_2d.py D:\path\to\preview --describe
```

未指定端口时由系统分配空闲端口。HTTP 服务固定绑定 `127.0.0.1`，只提供页面、清单与匿名 PNG token；不暴露源目录绝对路径。所有非 GET 写请求都会被拒绝。

## 控件与证据边界

- 播放/暂停、上一帧/下一帧、进度拖动与序列选择；
- 按源数据、循环或单次结束；速度与 1–6 倍整数缩放；
- 透明棋盘背景、坐标原点和当前帧裁剪框；
- PNG 逐帧与 `sprite-sheet + atlas + timeline` 使用同一个预览界面。

普通像素动画按 atlas 切图并按 timeline 播放，帧号空洞使用上一张关键帧。战斗特效中的 `parts` 骨架、图层矩阵与补间尚未复刻；涉及这些数据时，本工具只能作为**帧墙**检查，不代表游戏内最终表现。

## 安全限制

- 源目录、PNG 和元数据必须是普通文件/目录；拒绝符号链接和 Windows reparse point；
- 封印包存在多个 manifest 声明的 pixelart 根时拒绝，不会自行猜选角色；
- 元数据上限 8 MiB、单 PNG 上限 64 MiB、单次最多 4096 帧；
- 读取时校验文件身份，预览加载后源 PNG 漂移会中止请求；
- 不写源目录、不创建 profile、不访问 live store/CDN/server/device。
