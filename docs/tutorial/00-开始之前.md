# 00｜开始之前

欢迎来到《世界弹射物语》国服（CN）离线修改工具新手教程。本套教程面向**不懂编程、不使用 AI、在 Windows 电脑上从零动手**的玩家，带你一步步搭好本地环境，并亲手完成第一次角色数据修改与还原。

---

## 一、这套工具是怎么工作的？

要在自己的电脑或手机上看到修改后的游戏效果，一共需要**三块拼图**配合：

1. **本地服务端**（上游开源项目 `DontBeAlarmed/startpoint-cn`）：运行在你的 Windows 电脑上，负责代替已停服的官方服务器响应登录、存档和下发更新包。
2. **安卓客户端**（装在电脑安卓模拟器或安卓手机里的游戏 App）：打过「跳过官方登录」和「指向你电脑局域网地址」两处基础补丁后，就能连上你的本地服务端。
3. **修改工具仓**（本仓库）：运行在你的 Windows 电脑上，用来查看和修改角色数值、词条、文案、立绘、像素小人与语音，并把改动打包成游戏认识的**增量更新包（`.zip`）**。

**为什么改完不用每次重装 APK？**
游戏的大部分角色表和资源并不写死在 APK 安装包里，而是放在**数据包（`orderedmap` 表与图片音频）**以及**服务端配置（`assets/` 目录下的 JSON）**两处。本工具把你的改动打成更高一版的增量包（例如从官方基准 `1.4.54` 升到 `1.4.55`），客户端重开游戏时就会自动下载新版本并生效。

## 二、重要边界与安全须知

动手前请先确认以下三条原则：

- **本仓库不提供任何游戏本体文件**：本仓库仅包含开源工具代码与操作文档，**不包含、不分发任何客户端 APK、官方 CDN 数据包、立绘、像素或语音等受版权保护的游戏资产，也不提供任何下载渠道**。下文列出的官方原始文件均须由你自行合法准备。
- **仅限本机与家庭局域网自用**：服务端默认带免鉴权管理后台，**绝对不要**通过路由器端口映射、公网云服务器或内网穿透把服务端端口（尤其是 `8001`）暴露到公网。
- **遇到报错不要慌，也不要乱删已发布的包**：每一步都写明了检查办法；如果遇到红字提示，直接去 [07-报错对照表.md](07-报错对照表.md) 按原话搜索即可。

## 三、动手前自查清单

在进入下一篇之前，请先做一次准备核对，并创建一个统一的工作文件夹。

### 第 1 步：准备纯英文工作目录与磁盘空间

#### 做什么

1. 打开「此电脑」，找一个剩余空间充足的磁盘分区（建议预留 **至少 30 GB 可用空间**：官方 CDN 约 10 GB、本地物化数据包约 6 GB，其余留给服务端、工具与安卓模拟器）。
2. 在该分区下新建一个**纯英文、不带空格、不带中文**的总文件夹，用来集中存放后面所有的软件项目。
   *(全文统一用 `<工作目录>` 代指这个总文件夹；请不要把它建在「桌面」「文档」或带中文名字的用户目录里，避免部分命令行工具因路径编码报错。)*

#### 预期看到什么

- 资源管理器里能打开新建好的空文件夹 `<工作目录>`，路径中只有英文字母、数字、下划线或连字符。
- 所在分区的可用空间大于 30 GB。

#### 不对怎么办

- 如果分区空间不足 30 GB：换一个空间更大的分区新建 `<工作目录>`，或先清理闲置大文件。
- 如果路径里含有中文或空格（例如 `新建文件夹` 或 `WF Mod`）：右键重命名为纯英文（例如 `WFWork`）。

---

### 第 2 步：核对三项自备材料

请确认你手头已经自行备齐以下三样材料（现在只需确认文件在手，具体放到哪个子目录、怎么校验完整性，会在第 02、03 篇手把手带你检查）：

#### 做什么

逐项核对你自备的文件与运行设备：

1. **国服官方 `1.4.54` 完整本地 CDN 数据包**（约 10 GB）：
   解压后应能看到 `archive-common-full`、`archive-medium-full`、`archive-android-full`、`archive-common-diff`、`archive-medium-diff`、`archive-android-diff` 六个文件夹，以及装有 `10939-android_medium.csv` 清单的 `EntityLists`（或 `entities`）文件夹。
2. **国服官方 `1.8.1` 原版 Android 客户端安装包（`.apk`）**：
   包名为 `com.leiting.wf` 的雷霆国服停服前最终版 APK（用压缩软件打开看一眼，里面应有 `assets/worldflipper_android_release.swf`）。
3. **运行游戏的安卓环境（二选一）**：
   - **方案 A（新手推荐，全在一台电脑上完成）**：64 位安卓模拟器（如 MuMu 模拟器 12）。
   - **方案 B**：与电脑连在**同一个家庭路由器 Wi-Fi** 下的 Android 手机（电脑不能和手机处在不同网段或开启访客网络隔离）。

#### 预期看到什么

- 上述两份自备原始文件均已存放在你找得到的本地位置，且安卓模拟器或安卓手机可正常开机打开应用。

#### 不对怎么办

- 如果你的 CDN 文件夹里缺少上述 6 个 `archive-*` 目录之一，或总大小明显远小于 10 GB：说明这是一份残缺包，后续第 02 篇做校验时会通不过，请先找齐完整的 `1.4.54` 数据包再继续。
- 如果你拿到的是日服、台服或国际服 APK（包名不是 `com.leiting.wf`）：无法配合本套国服服务端与国服数据包使用，需准备国服 `1.8.1` 原版 APK。

## 四、全文占位符约定

为了保护隐私并适配每台电脑的不同安装位置，本套教程所有路径和地址都用尖括号 `<占位符>` 表示。你在敲命令或填配置时，**把连同尖括号在内的整段词替换成你电脑上的真实内容**即可：

| 占位符 | 含义 | 推荐放在哪里 |
|---|---|---|
| `<工作目录>` | 你在第 1 步新建的纯英文总文件夹 | 你自己选的磁盘英文目录 |
| `<工具目录>` | 本修改工具仓库所在的文件夹 | `<工作目录>\startpoint-cn-mod-tools` |
| `<服务端目录>` | 国服服务端仓库所在的文件夹 | `<工作目录>\startpoint-cn` |
| `<物化目录>` | 从 CDN 解包出来的本地可读写数据包目录 | `<工作目录>\wf-store` |
| `<补丁工作目录>` | 第 03 篇解包和重签 APK 用的临时文件夹 | `<工作目录>\apk-patch` |
| `<电脑局域网IP>` | 你电脑在家庭路由器下的 IPv4 地址 | 第 02 篇用 `ipconfig` 查出 |

## 五、教程路线图（请按顺序阅读）

如果你是从零开始，请按 `01 → 06` 的顺序一步一步往下走，不要跳步：

1. **[01-安装基础软件.md](01-安装基础软件.md)**：安装 Python 3.11+、Git、Node.js 20+，下载本工具仓库并装好依赖。
2. **[02-部署服务端.md](02-部署服务端.md)**：下载国服服务端、放入自备 CDN 数据包并在本机启动服务。
3. **[03-安装客户端并连接.md](03-安装客户端并连接.md)**：给自备国服 `1.8.1` APK 打免登录与局域网地址补丁，安装进模拟器或手机并进入游戏主页。
4. **[04-配置工具.md](04-配置工具.md)**：物化本地 `store` 数据包，填写 `profiles/local.json`，跑通 20 项只读自检。
5. **[05-第一次改数据.md](05-第一次改数据.md)**：用图形修改器把一个角色的 HP 改成 `9999` → 预览 → 发布 → 进游戏看到变化 → 一键还原。
6. **[06-打开编辑台.md](06-打开编辑台.md)**：构建并打开新一代可视化 Studio 编辑台，只读浏览角色/像素/BOSS 并在草稿箱里安全试改。
7. **[07-报错对照表.md](07-报错对照表.md)**：安装、连服、启动工具、发布热更与游戏崩溃码的一站式排查速查表。
