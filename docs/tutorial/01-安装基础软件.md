# 01｜安装基础软件

本篇带你在 Windows 10 / 11（64 位）电脑上装齐修改工具和本地服务端都要用到的三款基础软件：**Python（3.11 及以上）**、**Node.js（20 LTS 或 22 LTS）**、**Git（可选推荐）**，并把本工具仓库的 Python 依赖包一次性装好。

---

## 小技巧：如何在任意文件夹打开「命令提示符」

本套教程所有命令都优先使用 Windows 自带的**命令提示符（`cmd`）**，而不使用 PowerShell（因为 Windows 默认安全策略常常会在 PowerShell 里拦截 `npm` 命令）。

在后面任何一步需要「在某个文件夹打开命令提示符」时，只需这样做：

1. 用文件资源管理器打开目标文件夹（例如你在 [00-开始之前.md](00-开始之前.md) 里建好的 `<工作目录>`）。
2. 用鼠标左键单击窗口顶部的**路径地址栏**（地址栏里的路径会被全选变蓝）。
3. 直接键盘输入 `cmd` 三个字母，然后按回车键。
4. 弹出的黑色窗口就是已经定位到该文件夹的命令提示符。

> **注意**：每安装完一款新软件，**必须先关掉旧的黑色命令提示符窗口，重新按上面方法打开一个新窗口**，新软件的环境变量才会生效。

---

## 第 1 步：安装 Python（必须 3.11 或更高版本）

本仓库的所有数据处理工具和编辑台后端都由 Python 驱动。代码中使用了 Python 3.11 新增的标准库接口（`hashlib.file_digest`），因此 **Python 3.10 及更早版本无法运行**，请安装 **Python 3.11、3.12 或 3.13（64 位）**。

### 做什么

1. 用浏览器打开 Python 官方下载页 <https://www.python.org/downloads/windows/>，下载 **Python 3.11 / 3.12 / 3.13** 的 **`Windows installer (64-bit)`** 安装程序。
2. 双击运行下载好的安装程序：
   - **最关键一步**：在安装界面的第一页最下方，**务必勾选 `Add python.exe to PATH`**（把 Python 加入系统环境变量）。
   - 然后点击上方的 **`Install Now`**，等待进度条走完，看到 `Setup was successful` 后点击 `Close`。
3. 按 `Win + R` 打开「运行」，输入 `cmd` 并回车，在新打开的命令提示符窗口中依次运行下面两条命令：

```bat
python -V
python -m pip -V
```

### 预期看到什么

- 第一条命令打印 `Python 3.11.x`、`Python 3.12.x` 或更高的版本号（主次版本号 **不低于 3.11**）。
- 第二条命令打印 `pip ... from ... (python 3.1x)`，没有报错。

### 不对怎么办

- 报 `'python' 不是内部或外部命令`，或敲 `python` 反而自动弹出了微软应用商店（Microsoft Store）：
  1. 说明刚才安装时漏勾了 `Add python.exe to PATH`，或者被 Windows 应用商店别名抢占了。
  2. 重新双击刚才的 Python 安装包：若看到 `Modify`，点 `Modify -> Next -> 勾选 Add Python to environment variables -> Install`；或者先卸载再重装并勾上第一页底部的 `Add python.exe to PATH`。
  3. 若仍弹微软商店：打开 Windows「设置 -> 应用 -> 高级应用设置 -> 应用执行别名」，把列表里的 **`应用安装程序 python.exe`** 和 **`应用安装程序 python3.exe`** 两个开关**关掉**，然后重开一个命令提示符窗口再试。
- 显示版本是 `Python 3.10.x`、`3.9.x` 或 `2.7.x`：请先在 Windows「设置 -> 应用 -> 已安装的应用」里卸载旧版（或调整系统 `PATH` 顺序），再安装 Python 3.11 及以上版本。

## 第 2 步：安装 Node.js（20 LTS 或 22 LTS）

下一篇部署国服服务端（[02-部署服务端.md](02-部署服务端.md)）以及第 06 篇构建 Studio 编辑台前端网页（[06-打开编辑台.md](06-打开编辑台.md)）都需要 Node.js，且版本须 **不低于 `20.12.0`**。请优先选择 **LTS（长期支持版，20 LTS 或 22 LTS）**，避开奇数号或刚发布的实验版，以免服务端数据库组件缺少预编译包。

### 做什么

1. 用浏览器打开 Node.js 官方网站 <https://nodejs.org/>，下载 **20 LTS** 或 **22 LTS** 的 Windows 安装包（`.msi`，64-bit）。
2. 双击运行 `.msi` 安装包，全程保持默认勾选项，一路点击 `Next` 直至 `Install -> Finish`（其中若有 `Tools for Native Modules` 可选页，**不需要**勾选，避免自动下载几个 GB 的编译套件）。
3. **关闭旧的命令提示符窗口**，重新按 `Win + R` 输入 `cmd` 打开一个新窗口，依次运行：

```bat
node -v
npm -v
```

### 预期看到什么

- `node -v` 输出 `v20.12.0` 或更高的 `v20.x.x` / `v22.x.x` 版本号。
- `npm -v` 输出一串数字版本号（如 `10.x.x`）。

### 不对怎么办

- 报 `'node' 不是内部或外部命令`：先确认是否关闭了旧窗口并重开了新的 `cmd`；若重开仍找不到，重启一次电脑或重新运行 Node.js `.msi` 安装包选择 `Repair`。
- 如果你习惯在 PowerShell 里操作，运行 `npm -v` 时报 `因为在此系统上禁止运行脚本`：请改用本文开头介绍的 **`cmd` 命令提示符**，或者把命令里的 `npm` 写成 `npm.cmd`。

## 第 3 步：安装 Git for Windows（推荐）

装好 Git 后，你可以用一条 `git clone` 命令拉取本工具仓库和服务端仓库，日后更新也更省事。

### 做什么

1. 用浏览器打开 Git 官方下载页 <https://git-scm.com/download/win>，下载 **64-bit Git for Windows Setup**。
2. 双击运行安装程序，全部保持默认选项，一路点击 `Next` 直至 `Install -> Finish`。
3. 重新打开一个新的 `cmd` 命令提示符窗口，运行：

```bat
git --version
```

### 预期看到什么

- 窗口打印 `git version 2.x.x.windows.x`。

### 不对怎么办

- 如果因为网络原因暂时下不动 Git：这一步可以跳过。后续需要下载代码仓库时，在仓库网页右上角点击绿色的 **`<> Code -> Download ZIP`** 下载压缩包并手工解压即可（解压后注意检查别多套一层文件夹）。

## 第 4 步：准备本工具仓库并安装 Python 依赖

现在把本修改工具仓库放到 `<工作目录>` 下，并把工具所需的 4 个第三方 Python 库（`Pillow`、`numpy`、`PyYAML`、`jsonschema`）装好。

### 做什么

1. 打开 `<工作目录>`：
   - 如果你**已经**在电脑上下载好了本仓库（正在本地阅读本文），请把整个仓库文件夹移动或复制到 `<工作目录>` 下，确认文件夹路径纯英文无空格（下文将该文件夹统一记作 `<工具目录>`）。
   - 如果你是在网页上阅读本文、电脑上还没有下载本仓库：在 `<工作目录>` 地址栏输入 `cmd` 回车，用 `git clone <本仓库Git地址>` 克隆，或在仓库网页点 `<> Code -> Download ZIP` 解压到 `<工作目录>` 下得到 `<工具目录>`。
2. 用资源管理器点进 `<工具目录>`，在顶部路径地址栏输入 `cmd` 并回车，先核对当前目录位置是否正确：

```bat
dir wf_gui.py requirements.txt profiles\example.json
```

3. 确认三个文件都能列出后，继续在同一个命令提示符窗口运行依赖安装命令：

```bat
python -m pip install -r requirements.txt
```

4. 安装结束后，运行下面这条自检命令确认 4 个库都能正常导入：

```bat
python -c "import PIL, numpy, yaml, jsonschema; print('DEPS_OK')"
```

### 预期看到什么

- `dir` 命令顺利列出 `wf_gui.py`、`requirements.txt` 和 `example.json`，没有提示「找不到文件」。
- `pip install` 末尾显示 `Successfully installed ...`（或 `Requirement already satisfied`），没有红色的 `ERROR:`。
- 最后一条自检命令准确打印出 **`DEPS_OK`**。

### 不对怎么办

- `dir` 提示「找不到文件」：说明多套了一层子文件夹（解压 `Download ZIP` 常见，例如 `<工具目录>` 里面还有一个 `...-master` 子目录）。点进内层文件夹，把所有内容剪切移到外层 `<工具目录>`，确保 `wf_gui.py` 直接在 `<工具目录>` 底下。
- `pip install` 下载极慢或报网络超时（`ReadTimeoutError`）：检查网络后重跑一次，或临时加上国内镜像源参数重试：
  ```bat
  python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```
- `pip install` 报编译 `Pillow` / `numpy` 失败（提示缺少 `Microsoft Visual C++ 14.0`）：通常是因为你装了刚发布不久、尚未提供预编译二进制包的极新版 Python（或装成了 32 位 Python）。请改用 **64 位 Python 3.11、3.12 或 3.13** 后重新执行。
