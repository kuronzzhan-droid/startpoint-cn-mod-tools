### 逆向成果(两个,都已落地成代码)

1. **敌方成长曲线容器**(`master/battle/enemy/{hp,atk,tp}/*_curve.orderedmap`)
   - 格式:中间节点 `[4字节LE长度][zlib(索引)]`;**叶子 = 裸 zlib 流(无长度前缀)**
   - 索引:`<I count> + count×<II 累积名长, 累积数据长> + 名字拼接`,**两列都是累积结束偏移**
   - 解出 lv100:`hit_hp_boss` 78.27 / `non_element` 31.66 / `funnel` 12.81
   - ⇒ **真实血量 = 基数(c2) × 倍率(c3) × 修正曲线[c4][等级]**
   - 代码:`wf_rogue_build.growth_curves()` / `curve_value()`
2. **quest 表数值列位**(客户端反编译实锤,非猜测)
   - 源:`弹国服/scripts/pinball/master/generated/*QuestValues.as`
   - 以 `battle_field_data_id` 列 **f** 为原点:**f-12=hp_zako / f-11=hp_funnel /
     f-10=hp_boss / f-9=atk_zako / f-8=atk_funnel / f-7=atk_boss / f-6..-4=tp / f-3=enemy_level**
   - **20 张表 100% 一致**。以后查任何 quest 表的数值列不用再猜。
