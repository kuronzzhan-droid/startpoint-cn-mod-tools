# WF mod 分享包收方指南

> 面向:运行 startpoint-cn 私服、想使用他人 mod 内容的服主。
> **收方不需要安装任何 mod 工具**——本指南只涉及"把文件放对位置"。

## 分享包长什么样

```
wfshare-<起始>-to-<目标>/
├── archive-common-diff/      增量归档(主要内容)
├── archive-medium-diff/      中画质层(多为占位包)
├── archive-android-diff/     平台层(多为占位包)
├── dev-catalog/              dev 架构服务端专用材料(main 服务端忽略)
│   ├── catalog-cn-<目标>.json      整链候选 manifest
│   └── EntityLists/…csv            合并资源清单
├── requires.json             机器可读依赖声明
└── 说明.txt                  本包摘要
```

## 前提:链尾衔接

增量包只对"链尾恰好达到包起始版本"的服务端生效。查看自己的链尾:

```bash
ls .cdn/cn/archive-common-diff/ | sort -V | tail -3
```

文件名 `pinball-<from>-<to>-…` 里最大的 `<to>` 就是你的链尾。链尾低于包起始版本时,先向 mod 作者索要覆盖你版本的累计包;`since=1.4.54` 的完整链包适用于所有拥有官方 1.4.54 dump 的服务端。

## main 服务端(当前主流)

1. 把包内 `archive-common-diff/`、`archive-medium-diff/`、`archive-android-diff/`
   三个目录**解压合并**到你的 CDN 根(`.cdn/cn/`)对应目录——只增文件,不覆盖不删除;
2. 服务端动态扫描,无需任何配置;玩家客户端重启游戏即自动下载更新;
3. 查看 `requires.json`:
   - `serverRestart: true` → 重启一次服务端(通常因为包含新角色,邮件白名单启动定格);
   - `minServerVersion` / `serverFeatures` 非空 → 该包依赖服务端逻辑(如新玩法模式),
     你的服务端版本必须满足,否则内容会异常(进本崩溃/结算错误);
   - `clientPatches` 非空 → 玩家客户端需要对应补丁版 APK。
4. **不要**把 `dev-catalog/EntityLists/` 拷到 CDN 根——main 服务端会优先读取该目录
   并改变 files_list 行为。

## dev 架构服务端(content:sync)

1. 同上解压合并三个归档目录;
2. 把 `dev-catalog/EntityLists/` 整目录拷到 CDN 根,成为 `.cdn/cn/EntityLists/`;
3. 用受支持入口重启(`npm run start:cn` 等),启动同步会校验并重建 Content Release;
4. `dev-catalog/catalog-cn-<目标>.json` 是整链候选 manifest,对应
   "官方 dump + 完整 mod 链"的状态,可用于离线校验、评审或 tracked 基线兜底路线。

## requires.json 字段速查

| 字段 | 含义 |
|---|---|
| `requires.serverRestart` | 放入后需重启服务端一次 |
| `requires.restartReasons` | 触发重启的原因(自动检测) |
| `requires.minServerVersion` | 最低服务端版本/分支(模式类内容) |
| `requires.serverFeatures` | 依赖的服务端功能名 |
| `requires.clientPatches` | 玩家客户端需要的补丁 |
| `requires.serverDataNote` | 服务端派生表的额外说明 |

## 常见问题

- **客户端说"已是最新"不下载**:链尾不衔接(见"前提"),或客户端 res_ver 已高于包目标版本;
- **邮件发不出新角色**:`serverRestart` 没执行,重启服务端;
- **进新玩法崩溃**:服务端不满足 `minServerVersion`/`serverFeatures`,内容包不携带服务端逻辑;
- **回滚**:删除本包新增的 zip 文件即可(包只增不改;若客户端已下载,需清客户端资源缓存或等更高版本修复包)。
