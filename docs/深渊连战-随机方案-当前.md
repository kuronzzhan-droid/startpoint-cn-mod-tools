## 四、四道筛子(按顺序作用)

1. **引用完整性门禁**(硬,拦崩溃)
   `quest c98 → field_data → zone → boss/zako 代号`,代号必须在
   **general_boss ∪ standard_boss ∪ general_zako ∪ 10 张专用表**。
   外加**等级可行性**六根因:引用悬空 / sb 键过低 / gv 过高 / gv-gb 错配 /
   gv 单档100 / **funnel 档不够**(技能召唤物,第六根因)。
2. **黑名单**(策略,不拦崩溃)
   楼层:`treasure_cave*`(宝物域)。boss:`arch_evil*`(C8016 召唤色替)。
3. **分级收敛** `collapse_grades`:同一个 boss 只留**最高难度**的那个场地
   (先比敌等级、再比 field 尾号)。
4. **超级起步门槛** `MIN_QUEST_LEVEL = 80`:只留官方敌等级 ≥80(超级/超级+/地狱)的场地。
   ⚠ 「主线boss」池走 `NO_LEVEL_FLOOR` **不吃这道**——主线关官方等级只有 30–80,
   按档位刷会全军覆没,它的难度由 `resolve_level` 取 boss 最强档 + 轮次曲线决定。

## 五、去重与配额

**每座塔**的出场名额,按去重键计数(`used_counts`):

| 键 | 30 层配额 | 说明 |
|---|---|---|
| 普通 boss | **1** | 键 = 模型族 + 攻击程序签名 |
| 精灵兽 `spirit_beast` | **2** | 元素变体系列 |
| 女王 `variant_empress` | **2** | 同上 |
| 荒龙 `discarded_dragon` | **2** | 同上 |
| 机兵 `steampunk` | **3** | 同上(**排除** `steampunk_another`=菲诺梅那) |

配额按层数线性缩放:`round(base × rounds / 30)`,下限 1。
15 层 → 机兵 2 / 其余 1;60 层 → 机兵 6 / 其余 4。

⚠ 三条容易搞错的:
- 配额按**去重键**消耗,不按 boss 代号。墨之女王一层挂 4 个代号(两形态×单/多人槽),
  同层只吃 **1** 个名额。
- **去重键 ≠ 分级键**。全塔去重用系列键,`collapse_grades` 用细粒度键——共用的话
  池子层面六元素会被压成 1 条(实测机兵池 6→1,以后永远只出红机兵)。
- 八岐大蛇各头**不受系列规则影响**:它模型名本来就是 `orochi`,各头靠程序签名共存。

**跨塔**降权:`work/rogue_boss_history.json` 记最近 3 座塔,抽取时 80% 概率偏好
最近两座塔没出过的 boss。

## 六、抽取顺序(每个锚位)

```
候选池
  → unused_only    配额未满的才留(满了就全池放行,防排程塌掉)
  → prefer_fresh   80% 概率只从"最近两座塔没出过"的里挑
  → weight_featured 精选前缀候选重复 4 份(概率×4,不是硬钉)
  → rng.randrange  均匀抽一个
```

精选名单 15 个前缀(`rogue_special_bosses.json` 的 `featured_bosses`):
八岐大蛇×2、海妖、五元素球×5、指挥者、东亚奇廉CEO、索拉斯不死王/猫头鹰×5。

## 七、难度

端点式曲线,**起终点与层数无关**(8 层和 30 层同样的起终难度),
`growth = (终/起)^(1/(n-1))`。

| 预设 | hp 起→终 | atk 起→终 | 诅咒档 |
|---|---|---|---|
| easy | 0.4 → 2.0 | 0.3 → 1.2 | off |
| normal | 0.9 → 12.0 | 0.6 → 6.0 | abyss |
| **hell**(默认/主推) | **1.5 → 45.0** | **1.0 → 18.0** | 全塔 hell |
| gradient | 1.0 → 30.0 | 0.7 → 12.0 | 按深度四段递进 |

`--difficulty` 的 **CLI 默认值就是 `hell`**(2026-07-29 起),裸跑即全塔烈狱。

诅咒档:hell 预设全塔恒 hell;gradient 按深度递进
(≤25% off → ≤50% standard → ≤75% abyss → >75% hell)。
⚠ **工坊布局计划会盖掉深度递进**:`rogue_layout_plan.json` 的 `stages` 目前把
第 1–15 层全标成 `tier=hell`,`PLAN_TIERS["hell"] = ("hell", 1.15)` ⇒ 前半塔强制 hell
**并额外乘 1.15** 的 hp/atk。深度四段只在没有布局计划(或第 16 层起)时生效。

**来源补偿**(叠乘在轮次曲线上,因为这些来源基础数值低):
小怪房 hp×2.5/atk×1.6、杂鱼boss ×2.2/×1.5、领主战 ×1.8/×1.4;
塔层按区域深浅另有 ×1.6/×1.3(区域≤6)、×1.3/×1.15(7–8)。

**敌等级** `--enemy-level max`(默认):每层取该 boss 数据里的**最高可行档**,
所以绝大多数层是 100。**例外不止 80/79** —— 落在哪一档完全取决于该 boss 的等级表里
有什么键。全池扫描实测可达档位:`100 / 89 / 80 / 79 / 69 / 59 / 50 / 49 / 30`。
- 80:赤之女王(form1/form2×单多人四代号)、伊尔梅塔雷、终始之龙
- **89**:基因巨龙 raid3(gv/gb 都只有单档 89)
- 79:`discarded_dragon_dark`、哈里达尔 —— 这两个是被 **funnel 门禁**从 100 压下来的
- 30–69:统领AI(50)、`middle_boss_dragon_smr20_raid2`(69)等

## 八、诅咒(12 种,炼狱档数值)

**烈狱档没有白板层**:≤15% 掉 1 个 / ≤40% 掉 2 个 / >40% 掉 3 个
(其余档位维持 ≤15% 白板 / ≤45% 1 个 / 其余 2 个)。
攻击类(嗜血/逆鳞/玻璃)每层至多 1 个。

**冲突闸** `curse_conflict()`:①四系全免疫(无解层) ②**同 kind 正负并存**(抗性/免疫 + 易伤,
自相矛盾)③条件槽超 5。同 kind **同号**则由 `merge_conds()` 取最强合并,腾槽位不算冲突。
⚠ 判据看**符号**不是"是不是 1.0":深渊壁垒+深渊逆鳞 **16/16 恒冲突**(壁垒盖全四系)。
9000 层采样复验:正负并存 0、同 kind 重复 0、槽溢出 0、无解层 0;现网 31 关复检 0 冲突。
工坊钉选走同一道闸。

**诅咒组合** 8 套(名额 ≥2 时 55% 整套落地):单通道 / 速攻 / 孤注 / 风暴 /

## 九、场地效果(深渊法阵)

目录 **134 项**,全部可进随机池,**均匀抽取**(每条目一票)。
出场加权:45% 概率把法阵提到候选队首。⚠ 但这个分支有 `caps["boss"]` 前置——
**只有该层 boss 是 general 系(约六成楼层)时才有载体**,其余层法阵整条被剔出候选。
所以实际是:**有载体的层里约四成**带场地效果,折算到全塔 **约 23%**
(30 种子 × 30 层实测 208/900 = 23.1%)。

| 分类 | 数量 | 例 |
|---|---|---|
| **环境** | **73** | 狂风领域·微风0.05·5秒·方向1 / 重力领域·引力5·10秒·中心 |
| 加成 | 33 | 攻击+300% / 连击加成+20 / 充能+100% / 贯通 |
| 诅咒 | 23 | 技能伤害-300% / 连击限制+40 / 禁疗 / 血滑 |
| 场地 | 3 | 深渊之水(全场淹水)×2 / 元素统一场 |
| 领域 | 2 | 元素结界 / 炎兽领域(雷系兄弟=**雷电领域**在「加成」类) |

环境场 = `CreateWindAttack`(27 变体)+ `CreateGravitationalField`(46 变体),
**1.4.238 真机验证通过**。强度跨 20 倍、时长 4.7–50 秒、重力四种锚点,
标签已把参数编进 note(56 种不同说明)。

法阵载体 = 克隆该层 boss(`mod_rogue_bossN`)在现役 action 后追加场程序。
⚠ **要求该层 boss 是 general 系**;抽到 standard 系或专用表 boss(如八岐大蛇)
时法阵**静默落不上**——没效果先查这个,不是崩溃。
