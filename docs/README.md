# 文档总目录

本页是仓库全部文档的总导航。按「教程 tutorial / 手册 guide / 经验 experience / 现行参考 / 历史记录」五类整理，每份文档标注一句话说明与当前状态（`现行` / `部分过期` / `历史`）。

- **第一次接触本工具的新手**：请从**「一、教程（tutorial）」**按编号 `00 → 07` 顺序阅读。
- **已经配好环境、想按任务查怎么做**：直接查**「二、手册（guide）」**的五篇实操手册。
- **踩坑排错与机制深挖**：查**「三、经验（experience）」**与**「四、现行参考」**。
- **注意**：标记为 `部分过期` 的早期文档中常残留拆仓前的 `mod-tools/` 命令前缀或旧 `profiles.json` 写法；实操命令请一律以**「二、手册（guide）」**、[`../profiles/README.md`](../profiles/README.md) 及各命令 `--help` 输出为准。
