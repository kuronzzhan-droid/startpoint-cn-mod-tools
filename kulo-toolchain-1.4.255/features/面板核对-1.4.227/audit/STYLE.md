# MOD 角色面板文案规范 v1（草案）

依据：客户端官方文案模板（ui_string `ability_description_*`，533 条，原文在 official_templates.tsv）、游戏内「帮助（战斗）」的乘区说明、作者已定的面板规则。
只管**面板覆盖文案**（desc_override_*）；没有覆盖的条目由客户端自动生成，本来就是官方格式。

## 1. 一行一条，句式固定
`[条件，]对象 效果 数值[（乘区）][（上限/CT/持续）]`
- 例：`水属性共鸣时，水属性角色技能伤害+15%（独立伤害乘区7）`
- 例：`每发动3次强化弹射，自身攻击力+10%（最多10次）`
- 一条能力里条件不同的效果分行；条件和对象都相同的多个效果合成一句，用「、」连接：`自身攻击力+50%、技能伤害+50%`。
- 句末不加句号。

## 2. 条件前缀顺序
主位图标 → 属性共鸣 → 状态/模式 → 触发。
- 共鸣：`X属性共鸣时，`
- Fever：`Fever模式中，`／`非Fever模式中，`／`进入Fever模式时，`
- 战斗开始：`战斗开始时，`
- 持有状态：`自身处于「X」状态时，`／`贯穿效果中，`
- 计数触发：`每达成N连击，`／`每发动N次强化弹射，`／`每直接攻击N次，`／`每经过N秒，`
- 层数：`「X」每1层，…（最多N层）`
- 主位限制的能力：每行开头保留主位图标；文字里不再写「主位时」。
- 队长槽不写「自身为队长时」。
- 数据放在能力里、但带「队长」前置的效果，文字写进队长技覆盖文案（去掉「担任队长时」），能力里不再重复；能力只剩这类效果时写「效果写在队长技中」。（作者1017）

## 3. 术语统一（左边是要替换掉的写法）
| 不用 | 统一为 |
|---|---|
| PF、Power Flip、强化弹射伤害提升效果 | 强化弹射 / 强化弹射伤害 |
| 直击、直击伤害、直接攻击造成的伤害 | 直接攻击 / 直接攻击伤害 |
| FEVER、fever、FEVER槽 | Fever模式 / Fever槽 |
| 贯通 | 贯穿效果 |
| 全体队员、队伍全体角色、全队 | 队伍全体 |
| 除自身外的X属性角色 | 除自身外的X属性角色（照旧） |
| 技能槽上限 | 技能槽最大值 |
| 充能速度 | 技能充能速度 |
| 眩晕畏缩特攻、对眩晕敌人的伤害 | 追击伤害（对虚弱中的敌人），属乘区3；对「麻痹・气绝」状态敌人的加成（官方名「麻痹・气绝效果」）属乘区2，两者不要混写 |
| 额外乘区、（独立乘区）、状态特攻乘区 | （独立伤害乘区N） |

## 4. 数值写法
- 一律 `+X%`／`-X%`（半角加减号）；倍率写 `X倍`；连击写 `连击+N`。
- 上限：次数用 `（最多N次）`，层数用 `（最多N层）`，累计量用 `（最大+Y%）`；有了次数就不再重复写累计量。
- 冷却：`（CT：N秒）`；持续：`（持续N秒）`；只触发一次：`（仅1次）`。
- 只写满级数值，不写两档（不写「觉醒后」）。

## 5. 独立伤害乘区
属于 9 个乘区的效果在数值后加 `（独立伤害乘区N）`（乘区9 为官方全角「９」），其余不加。
1 特攻　2 对特定状态敌人（全伤害型）　3 追击　4 逆境　5 强化弹射　6 直接攻击／带伤害的连击（直接攻击计算为N次）　7 技能　8 能力　9 全伤害

## 6. 自创机制的固定说法
- 固有状态：名称一律用「」，第一次出现时说明怎么获得：`每发动3次强化弹射，自身获得1层「回响」`。
- 追加技能（629）：`发动「技能名」（造成技能伤害，CT：N秒）`；伤害类型只在不是技能伤害时注明（如「以强化弹射伤害计算」）。
- 特殊强化弹射：`自身的强化弹射变为「名称」：一句话说明`；详细数值不写。
- 技能强化：只写在队长技／能力，格式 `强化『技能名』：定性说明`，不写数字；技能描述里不重复。
- 改冲刺：`强化自身冲刺：一句话说明`；「冲刺间隔缩短效果不会让自身冲刺冷却进一步缩短」这类限制保留。

## 7. 该省略的
- 不写恒真条件（如「生命值100%以下」）、实现细节（「不消耗技能槽」以外的内部说明）、重复的主语。
- 同一句里已写过的条件不再重复。
- 能力里看不出来的副作用不省（如「最后一击后连击归零」要保留）。

## 8. 不动的
- 数值、条件、效果本身：数据说了算，文案只改写法。
- 名称：技能名、状态名、角色名保持现有译名。
## 9. 技能描述（action_skill，两档同一套写法）
照官方技能说明的写法，例：「向距离最近的敌人突进，对碰撞到的敌人造成暗属性伤害（伤害量以直接攻击伤害判定）／赋予队伍贯穿＋最大速度固定效果」。
- 结构：`动作，对象造成X属性伤害[（伤害量以Y伤害判定）]／附加效果1／附加效果2`，效果之间用「／」，同类效果用「＋」连。
- 条件分支用官方的【】：`【场上没有协力球时】召唤2个「魔物万圣南瓜」协力球【场上有协力球时】吞噬…`。
- 官方技能描述不写伤害倍率和段数，我们也不写（作者 1017 已确认）（「合计43倍」「3段×2倍率」删掉）；buff 只写「X提升效果」不写百分比；持续秒数、层数上限这类玩家需要的可以保留在括号里。
- 只写技能本体；队长技／能力带来的强化不写进技能描述（作者 0927 规则）。

## 10. 自创机制专项
| 机制 | 统一写法 | 例 |
|---|---|---|
| 伤害按其他类型结算 | `（伤害量以X伤害判定）`，官方原话，放在伤害后面 | 杰拉德「月耀一闪」：`…造成光属性伤害（伤害量以直接攻击伤害判定）` |
| 六属性各打一次的能力伤害 | `对全体敌人造成自身攻击力N倍的六属性能力伤害（火／水／雷／风／光／暗各结算1次）`，一句合并，不拆 6 行 | 杰拉德：每弹射10次 |
| 直接攻击倍率 | `自身直接攻击的基础伤害变为N倍，每1连击再+X%（无上限）` | 凯尔 |
| 直接攻击判定次数 | 官方说法 `直接攻击计算为N次，合计伤害+X%（独立伤害乘区6）`；随层数增加的写 `「X」每1层，自身直接攻击计算次数+1` | 凯尔「月牙」 |
| 多段命中的特殊强化弹射 | `「X」每N层，强化弹射命中次数+1（最多+M次）` | 凯尔队长 |
| 多重强化弹射 | `自身的强化弹射同时发动A型与B型`；三种以上用「、」连接、最后一个用「与」，五种全发动写「同时发动全部类型」（作者1017）；附带强化写冒号后（定性）；形态各异按形态分句：`「龙人」形态中，强化弹射同时发动射击型与特殊型；「真龙」形态中，同时发动全部类型`。类型名只用剑士型／格斗型／射击型／辅助型／特殊型，不写「同时具备」「同时生效」 | 赛瑞斯、夏日白、酒馆骑士 |
| 强化弹射Lv4 | `强化弹射Lv4「名称」：发动条件。效果（一句）`，条件写全（模式、连击门槛），效果定性 | 赛瑞斯：`Fever模式中弹射时连击100以上，强化弹射升级为Lv4「苍海怒涛」：范围与威力提升，追加2段强化弹射伤害` |
| 形态切换 | 第一次出现时写清进出条件：`进入Fever模式时化身「真龙」，Fever模式结束时恢复「龙人」`；之后只写 `「真龙」形态中，` | 赛瑞斯 |
| 技能形态切换／技能强化 | `强化『技能名』：定性说明`，不写数字 | 杰拉德能力3 |
| 场地道具／箭头替换 | `Fever模式中，场上的加速箭头变为随机道具` | 赛瑞斯 |
| 按敌人生命值比例的伤害＋斩杀 | `对距离最近的敌人造成其当前生命值X%的伤害（每发动1次『技能名』再+Y%），该敌人生命值低于Z%时直接将其击败`；叫法统一为「当前生命值比例伤害」，不写「真伤」 | 杰拉德强化『月耀一闪』：5%起、每次+1%、低于5%击败 |
| 充能速度上限 | `自身技能充能速度上限提升至N%` | 凯尔、月兔 |
